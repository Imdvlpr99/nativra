# Nativra Expo NativeWind Example

This example demonstrates how Nativra components are consumed in an Expo project configured with **NativeWind v4**.

## Key Features

- **Source-first:** Components live in `components/ui/` without a runtime library.
- **NativeWind styling:** Tailwind utility classes directly compiled for React Native.
- **Full TypeScript:** Strictly typed prop contracts and variants.

## Getting Started

```bash
# Install dependencies
npm install # or pnpm install

# Start the Expo development server
npx expo start
```
