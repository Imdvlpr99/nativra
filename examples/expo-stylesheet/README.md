# Nativra Expo StyleSheet Example

This example demonstrates how Nativra components are consumed in an Expo project configured with **React Native StyleSheet**.

## Key Features

- **Source-first:** Components live in `components/ui/` without a runtime library.
- **Pure React Native:** Zero third-party CSS dependencies; uses `StyleSheet.create` and `useColorScheme()`.
- **Full TypeScript:** Strictly typed prop contracts and variants.

## Getting Started

```bash
# Install dependencies
npm install # or pnpm install

# Start the Expo development server
npx expo start
```
