# Chat & Messaging Flow

A complete Metronic-grade customer messaging and team inbox screen flow. Includes searchable conversation threads, active chat views with sent/received speech bubbles, and keyboard-avoiding message input.

## Installation

```bash
npx nativra add chat-flow
```

## Features

- **Inbox Thread Overview**: Multi-tab inbox (`All`, `Support`, `Direct`) with unread counters and online presence indicators.
- **Active Thread Screen**: Smooth speech bubbles with read-receipt checkmarks and timestamping.
- **Keyboard-Aware Input**: Built-in `KeyboardAvoidingView` with attachment action triggers and reactive send button.
