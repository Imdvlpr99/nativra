# Analytics Dashboard

An executive-level SaaS mobile dashboard template inspired by Metronic and shadcn. Features quick KPI metric overviews, time-range filter tabs, traffic channel progress bars, and recent system activity logs.

## Installation

```bash
npx nativra add analytics-dashboard
```

## Included Components & Blocks
- `Card`
- `Badge`
- `Button`
- `Separator`
- `Tabs`
- `Text`
- `MetricCard`
