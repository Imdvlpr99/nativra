# Account Settings Flow

A comprehensive Metronic-grade SaaS account management screen flow featuring profile administration, organization seat utilization, active session security revocation, and invoice history.

## Installation

```bash
npx nativra add account-settings-flow
```

## Features

- **Profile & Org Settings**: Manage corporate identities, contact details, and notification toggles.
- **Seat Utilization**: Visual progress bar tracking assigned organization seats against subscription quotas.
- **Security & Device Sessions**: Two-Factor Authentication switch, list of authenticated devices with IP/location, and immediate session revocation.
- **Billing & Invoices**: Current plan display, default payment method card, and invoice history ledger.
