# Fintech Wallet

A high-performance personal finance and crypto wallet dashboard template inspired by Metronic. Features total asset valuation, quick transfer/receive/swap action pills, portfolio asset allocation, and recent transaction records.

## Installation

```bash
npx nativra add fintech-wallet
```

## Included Components & Blocks
- `Card`
- `Badge`
- `Button`
- `Separator`
- `Text`
