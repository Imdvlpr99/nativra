# Dark Slate Theme

A slate-toned theme with a deep blue-grey dark palette and sky-blue accents.

## Install

Replace your current theme with Dark Slate. Every installed component picks it up:

```bash
npx nativra-cli theme add dark-slate --overwrite --apply-css
```

This writes `lib/themes/theme.ts` (your previous theme is backed up; `npx nativra-cli rollback dark-slate` restores it). `--apply-css` also rewrites the CSS variables in `global.css` that NativeWind components read; it has no effect with the StyleSheet target.

To keep your current theme and install Dark Slate alongside it, use `--as`:

```bash
npx nativra-cli theme add dark-slate --as dark-slate
```

## What the file exports

```ts
export const darkSlate = { background: "#f8fafc", primary: "#0284c7", /* … */ } as const;
export const darkSlateDark = { background: "#0f172a", primary: "#38bdf8", /* … */ } as const;

// What components read, through useThemeColors() or the CSS variables
export const themeColors = { light: darkSlate, dark: darkSlateDark } as const;
```

## Use the tokens in your own screens

```tsx
import { View, Text } from "react-native";
import { useThemeColors } from "@/hooks/use-theme-colors";

export function Banner() {
  const c = useThemeColors(); // follows the device's light/dark setting
  return (
    <View style={{ backgroundColor: c.card, borderColor: c.border, borderWidth: 1 }}>
      <Text style={{ color: c.foreground }}>Matches every Nativra component</Text>
    </View>
  );
}
```

With NativeWind, use the semantic classes instead: `bg-card`, `border-border`, `text-foreground`.

## Customization

The theme file is yours. Change a value in `theme.ts` (and, for NativeWind, the matching variable in `global.css`) to adjust that color everywhere.
