# App Header

An enterprise-ready navigation header block complying with Nativra V4 navigation standards. Includes title/branding, optional back button, integrated search bar, notifications badge trigger, and user profile avatar.

## Installation

```bash
npx nativra add app-header
```

## Features

- **Branding & Hierarchy**: Displays clear title and optional subtitle/breadcrumb.
- **Back Navigation**: Conditionally renders back button with tactile feedback.
- **Search Integration**: Optional integrated search bar with clear button.
- **Notifications Badge**: Action button with count indicator pill.
- **Avatar Trigger**: Profile picture with fallback initials.
- **Zero-Dependency Styling**: Fully implemented in NativeWind or pure React Native StyleSheet.
