# App Sidebar

An enterprise application navigation sidebar block complying with Nativra V4 navigation layouts. Suitable for tablet layouts, web views, or custom side drawer navigations.

## Installation

```bash
npx nativra add app-sidebar
```

## Features

- **Categorized Groups**: Organizes links into clearly labeled navigation sections.
- **Active State Highlights**: Prominent active indicator with pill styling.
- **Badge Indicators**: Displays notification or count pills on individual navigation items.
- **User Profile Footer**: Includes user avatar, name, email, and quick-action menu (Settings/Logout).
- **Styling Flexibility**: NativeWind or StyleSheet without extra runtime dependencies.
